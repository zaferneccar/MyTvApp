# MyTvApp — شاشة البيت على LG webOS

شاشة رئيسية خاصة فيك: ساعة وتاريخ، طقس، صور العيلة كخلفية متحركة، وأزرار للتطبيقات اللي بتهمك (والتطبيقات اللي عاملها إنت).

## شو بتعدّل؟

| بدك… | عدّل |
|---|---|
| تضيف أو تشيل تطبيقات | `js/config.js` ← `apps` و `myApps` |
| تحط صور العيلة | حطها بمجلد `photos/` وشغّل `npm run photos` |
| تغيّر المدينة أو اسم العيلة | `js/config.js` |
| تكتب ملاحظات من تلفونك | Google Sheet (شوف تحت) |
| تغيّر الألوان والشكل | `css/style.css` |

### كيف بعرف `id` أي تطبيق؟
افتح التطبيق على التلفزيون، وبعدين شغّل من الكمبيوتر:
```
npm run running
```

## 📝 لوحة الملاحظات (بتكتب من تلفونك من أي مكان)

الملاحظات محفوظة بـ **Google Sheet**، والتلفزيون بيقرأها كل دقيقة.

1. من تلفونك أو الكمبيوتر اعمل Google Sheet جديد، مثلاً اسمه "ملاحظات البيت".
2. **العمود A** للملاحظة، و**العمود B** لاسم اللي كتبها (اختياري). كل سطر ملاحظة، والأسطر الفاضية ما بتظهر.
3. من الكمبيوتر: **File ← Share ← Publish to web**، اختار الورقة الأولى و **Comma-separated values (.csv)**، واكبس **Publish**.
4. انسخ الرابط وحطه بـ `js/config.js` ← `notes.csvUrl`، وبعدين `npm run deploy`.

بعدها كل شي بتكتبه أو بتمسحه بتطبيق Google Sheets على تلفونك بيطلع على التلفزيون. Google بتأخّر التحديث شي دقيقة لخمس دقايق.
بتقدر تشارك الـ Sheet مع العيلة ليكتبوا كمان. الملاحظات الجديدة بتلمع أصفر لما تطلع.

> 🔒 رابط النشر صعب حدا يخمّنه، بس أي حدا معه الرابط بيقدر يقرا الملاحظات. لا تكتب فيها كلمات سر أو أشياء حساسة.

## أول مرة: تجهيز التلفزيون (مرة وحدة بس)

1. اعمل حساب مجاني على [webostv.developer.lge.com](https://webostv.developer.lge.com).
2. على التلفزيون: من **LG Content Store** نزّل تطبيق **Developer Mode** وفوت بنفس الحساب.
3. شغّل **Dev Mode Status** و **Key Server**، ودوّن الـ IP والـ Passphrase اللي بيطلعوا.
4. على الكمبيوتر (لازم يكون Node.js منزّل):
   ```
   npm install
   npx ares-setup-device      # Add ← name: tv ← IP التلفزيون ← port 9922 ← user: prisoner
   npx ares-novacom --device tv --getkey   # بيطلب الـ Passphrase
   ```

> ⚠️ وضع المطوّر بيخلص بعد 50 ساعة إذا ما جدّدته. فوت على تطبيق Developer Mode واكبس **Extend**.

### ما عندك كمبيوتر؟ استعمل تلفون أندرويد
نزّل **Termux** من [F-Droid](https://f-droid.org/packages/com.termux/)، وبعدين:
```
pkg update -y && pkg install -y nodejs git
git clone -b ccr-2a04982c-y0wjxr https://github.com/zaferneccar/MyTvApp
cd MyTvApp
npm install
```
وكمّل بنفس أوامر `ares-setup-device` و `--getkey` اللي فوق.

## التجربة والتثبيت

```
npm run preview   # تجربة على الكمبيوتر: http://localhost:8080
npm run deploy    # بيبني التطبيق وبيثبته وبيفتحه على التلفزيون
```

على الكمبيوتر الأسهم و Enter بيشتغلوا متل الريموت. فتح التطبيقات بيشتغل بس على التلفزيون.

## ملاحظة عن "الشاشة الرئيسية"
LG ما بتسمح تبدّل الشاشة الرئيسية الأصلية بدون Root. الحل العملي: انقل تطبيق **بيتي** لأول مكان بشريط التطبيقات (كبسة طويلة على OK)، وبيصير بكبسة وحدة من زر البيت.
بعدين إذا عملت Root (webOS Homebrew Channel) منقدر نخليه يفتح تلقائي أول ما يشتغل التلفزيون.
